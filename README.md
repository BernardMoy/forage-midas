# Midas
Project repo for the JPMC Advanced Software Engineering Forage program


# Task breakdown
Task 1 involves depndency setup in the maven xml file. It involves adding tags to include the required dependency. Also, include the title in the yaml file. 

Task 2 involves creating a listener class and modify the yaml file to include the serializer. 

Task 3 involves reading and updating the database according to the transaction that the listener listens. It also involves creating new classes to handle the transaction objects. 

Task 4 involves using a rest template to make a post request, returning an Incentive class. 

Task 5 involves creating a new rest controller class that also interacts with the database to get the user balance.
